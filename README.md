# Library Management System

A Python-based Personal Library Manager built using core Python concepts. Manage your book collection from the command line.

## Features

- Add new books with title, author, genre, year and read status
- List all books in the library
- List books sorted by year
- Search books by author name
- Delete a book by title
- Show reading summary (read vs unread %)
- Display all book titles in UPPERCASE
- Save library to a file
- Load library from a file

## Tech Stack

- Python 3
- Jupyter Notebook
- File Handling (txt)
- Core Python — lists, dictionaries, functions, loops

## Concepts Used

- CRUD Operations (Create, Read, Update, Delete)
- List comprehensions
- Lambda functions & sorting
- File I/O (save and load data)
- Menu-driven CLI application

## How to Run

1. Clone this repository
2. Open `PYTHON MINI PROJECT 1.ipynb` in Jupyter Notebook
3. Run the cell
4. Use the menu to interact with your library
